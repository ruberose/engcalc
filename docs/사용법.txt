1. 실행 방법
--------------------------------------------------------------------

1) 처음 한 번만: 필요한 패키지 설치
   pip install -r requirements.txt

2) 실행
   python main.py

   -> 격자 배경의 빈 창이 뜨면 정상입니다.

2. 캔버스 기본 조작법
--------------------------------------------------------------------

블록 만들기
   더블클릭            : 그 자리에 "수식 블록"을 만듭니다.
   Ctrl + 더블클릭     : 그 자리에 "텍스트 블록"을 만듭니다.
   (이 프로그램의 핵심 기능이 계산이므로, 아무 표시 없는 더블클릭의
    기본 동작은 수식 블록입니다. 제목/설명 등 글만 쓰고 싶을 때만
    Ctrl을 눌러주세요.)

블록 선택/이동
   블록 클릭           : 선택 (점선 테두리로 표시됨)
   블록을 드래그        : 이동
   빈 캔버스를 드래그    : 여러 블록을 한 번에 선택(러버밴드 선택)

블록 편집
   블록을 더블클릭      : 편집 모드로 들어감 (수식/텍스트 모두 동일)
   편집 중 바깥을 클릭   : 편집 종료 및 내용 반영
   편집 중 Enter        : (수식 블록만) 편집 종료 및 내용 반영

블록 삭제
   블록을 선택한 뒤 Delete 또는 Backspace

블록 잠금 (메뉴 > 편집 > 블록 잠그기 / 블록 잠금 해제)
   완성된 계산 블록을 실수로 옮기거나 고치지 않게 보호합니다. 블록을
   선택하고 "블록 잠그기"를 누르면:

      - 드래그로 이동이 안 됩니다(선택은 계속 가능).
      - 더블클릭으로 편집(수식 편집/Ctrl+더블클릭 단위 편집/텍스트 편집)이
        안 됩니다.
      - 크기 조절 손잡이가 사라집니다.
      - Delete/Backspace로 지워지지 않습니다(다른 블록과 같이 선택해서
        지워도 잠긴 것만 남습니다).
      - 정렬 기능의 대상/기준에서 빠집니다.
      - 우측 상단에 작은 🔒 표시가 뜨고, 선택 테두리가 회색으로 보입니다.

   "블록 잠금 해제"로 다시 풀 수 있습니다. 잠금 상태는 파일에 저장되어
   다시 열어도 유지됩니다. 복사/붙여넣기/복제한 블록은 원본의 잠금 상태를
   그대로 물려받습니다.

실행취소 / 다시실행 / 모두 선택 / 복사 / 붙여넣기 / 복제
   Ctrl+Z              : 실행취소 (블록 생성/삭제/이동/크기조절/내용변경/붙여넣기 등
                          문서에 생긴 변화를 한 단계씩 되돌림)
   Ctrl+Y              : 다시실행 (Ctrl+Z로 되돌린 것을 다시 앞으로)
   Ctrl+A              : 캔버스 위 모든 블록 선택
   Ctrl+C              : 선택된 블록(들) 복사
   Ctrl+V              : 복사한 블록(들)을 원본에서 살짝 어긋난 위치에 붙여넣기.
                          단, OS 클립보드에 이미지가 있으면(스크린샷 등) 그
                          이미지를 화면 중앙에 새 이미지 블록으로 붙여넣기
                          (6번 항목 "이미지 블록 사용법" 참고)
   Ctrl+D              : 선택된 블록(들)을 클립보드를 거치지 않고 바로 복제
                          (복사해둔 내용이 있어도 그대로 유지됩니다)

   메뉴 > 편집 에서도 같은 기능을 쓸 수 있습니다. 블록을 편집(타이핑) 중일 때는
   이 단축키들이 편집기 자체의 텍스트 실행취소/복사/붙여넣기로 쓰이고, 문서
   단위 동작은 편집 중이 아닐 때만 적용됩니다. 붙여넣은/복제된 블록은 새
   블록으로 취급되어(원본과 다른 고유 id) 원본과 독립적으로 움직이거나 지울
   수 있습니다. 실행취소 기록은 최근 50단계까지 보관됩니다.

찾기 (Ctrl+F)
   메뉴 > 편집 > 찾기 또는 Ctrl+F로 찾기 창을 엽니다. 검색어를 입력하면
   수식 블록의 입력 원문, 텍스트 블록의 내용, 이미지 캡션에서 찾아서 화면
   위→아래 순서로 첫 번째 결과 블록을 선택하고 그 위치로 화면을 옮겨줍니다.
   "다음"/"이전" 버튼(또는 Enter)으로 결과를 넘나들 수 있고, 마지막 결과에서
   "다음"을 누르면 다시 처음으로 돌아갑니다(원형). 계산 결과값이 아니라
   입력한 원문을 기준으로 찾습니다.

   도움말 창에도 따로 찾기 검색창이 있습니다(맨 위, Ctrl+F로 포커스 이동).
   지금 보고 있는 탭(기본 사용법/수식 작성법) 안의 텍스트에서 찾아 하이라이트해
   줍니다 — 메인 창의 찾기와는 별개로 동작합니다(서로 다른 창이라 단축키가
   따로 걸려 있습니다).

정렬 (메뉴 > 편집 > 정렬)
   블록을 2개 이상 선택하면(빈 캔버스를 드래그해서 여러 개 선택하거나,
   Ctrl/Shift+클릭으로 추가 선택) 정렬 메뉴가 활성화됩니다.

      왼쪽/오른쪽/위쪽/아래쪽 맞춤 : 선택된 블록들의 해당 변을 한 줄에 맞춥니다.
      가운데 맞춤 (가로)          : 선택 영역 전체의 가로 중앙에 맞춥니다.
      중간 맞춤 (세로)            : 선택 영역 전체의 세로 중앙에 맞춥니다.

   기준은 항상 "선택된 블록들 전체를 감싸는 사각형"입니다 — 예를 들어
   "왼쪽 맞춤"은 선택된 블록 중 가장 왼쪽에 있는 블록의 왼쪽 변에 나머지를
   맞춥니다. 실행취소(Ctrl+Z)로 되돌릴 수 있고, 정렬로 블록의 위아래 순서가
   바뀌면 계산도 그 순서에 맞게 다시 됩니다.

화면 조작
   마우스 휠               : 위/아래로 스크롤
   Ctrl + 마우스 휠         : 커서 위치를 중심으로 확대/축소
   휠 버튼(가운데 버튼)을 누른 채 드래그 : 캔버스 전체를 끌어당겨 이동(패닝)
   Space를 누른 채 드래그    : 캔버스 전체를 스크롤(패닝) — 휠 버튼 드래그와 같은 동작

격자 보기 켜기/끄기 (메뉴 > 보기 > 격자 보기)
   배경 격자를 껐다 켰다 할 수 있습니다. 화면을 깔끔하게 보고 싶을 때
   꺼두세요. 선택한 상태는 앱을 껐다 켜도 그대로 유지됩니다. PDF/PNG로
   내보내거나 인쇄할 때는 이 설정과 무관하게 항상 격자 없이 나갑니다
   (내보내는 동안만 잠깐 껐다가, 끝나면 화면은 원래 설정으로 되돌아옵니다).


--------------------------------------------------------------------
3. 수식 블록 사용법
--------------------------------------------------------------------

입력 형식은 두 가지입니다.

   (1) 변수 대입      예) a = 100
   (2) 그냥 계산식     예) a * 2 + 1

변수 대입을 하면 그 변수는 캔버스의 "아래쪽(또는 같은 높이면 오른쪽)"에
있는 다른 수식 블록에서 그대로 쓸 수 있습니다. 즉 블록은 화면에 놓인
위→아래, 왼→오른 순서대로 계산됩니다.

   [블록 1]  a = 100
   [블록 2]  a * sin(30)     ->  결과: 50   (a=100 을 이어받아 계산)

어떤 블록의 값을 바꾸면, 그 값을 참조하는 다른 모든 블록도
자동으로 다시 계산됩니다. 값을 계속 바꿔가며 검산할 때 편리합니다.

화면 표시 (한 줄 / 두 줄)
   기본적으로 "입력 = 결과"를 파워포인트 글상자처럼 한 줄로 표시합니다.
   (예: "A + B = 15 m". "a = 100"처럼 입력 자체가 이미 값이면 결과를
   중복해서 보여주지 않습니다.)

   블록을 클릭해서 선택하면 우측 가장자리에 작은 손잡이가 나타납니다.
   이 손잡이를 드래그해서 폭을 좁히면, 한 줄에 다 안 들어갈 때 입력 줄과
   "= 결과" 줄로 나뉩니다(줄바꿈). 폭을 다시 넓히거나 아예 손잡이를
   건드리지 않으면 항상 내용에 맞춰 한 줄로 넓어집니다. 줄바꿈은 보여주는
   방식만 바꿀 뿐, 계산 결과 자체는 바뀌지 않습니다.

   계산이 에러인 블록은 (한 줄/두 줄 모드 상관없이) 빨간색 글씨로 표시됩니다.
   흔한 원인은 단위 대소문자 오타("100mpa" — "100MPa"여야 함, 위 "단위 계산"
   항목 참고)나 정의되지 않은 변수를 참조한 경우입니다. 두 줄 모드에서는
   에러 메시지 원문도 결과 줄 자리에 함께 보입니다.

결과 단위 바로 바꾸기 (Ctrl+더블클릭)
   결과가 단위 있는 값(예: "5m + 6m = 11m")일 때, 블록을 Ctrl+더블클릭하면
   단위만 편집할 수 있는 작은 입력창이 뜹니다. 지금 단위("m")가 미리
   채워져 있고, 다른 단위(예: "mm")로 바꿔서 Enter를 누르면:

      5m + 6m = 11m   ->  (Ctrl+더블클릭, "mm"으로 변경) ->  5m + 6m = 11000mm

   값이 그 단위에 맞춰 자동으로 환산되어 보입니다. 실제 계산에 쓰이는
   값은 그대로이고(다른 블록의 계산에 영향 없음), 보여주는 단위만 바뀝니다.
   같은 걸 속성 패널의 "표시 단위" 입력으로도 할 수 있습니다.
   말이 안 되는 단위를 입력하면(예: "asdf") 조용히 무시되고 원래 값이
   그대로 보입니다. 단위 없는 순수 숫자나 에러 상태인 블록은 바꿀 단위가
   없어서 Ctrl+더블클릭해도 아무 일도 일어나지 않습니다.

지원하는 연산자
   +  -  *  /       사칙연산. 입력은 "*", "/"를 그대로 쓰지만, 화면에는 실제
                     수식처럼 보이게 바뀝니다 — "*"는 가운뎃점(·)으로, "/"는
                     진짜 분수 막대(a/b -> a가 위, b가 아래인 분수 모양)로
                     표시됩니다. 계산이나 저장되는 내용에는 차이가 없습니다.
                     (단, "a/b/c"처럼 나눗셈이 2개 이상 겹치면 어느 쪽으로
                     묶을지 모호해서 분수로 바꾸지 않고 그냥 슬래시로 둡니다.)
   ^                거듭제곱 (예: 2^10 = 1024)
   %                나머지
   <  >  <=  >=  == 비교 (결과가 True / False로 표시됨)

지원하는 함수
   sin, cos, tan             삼각함수 — 괄호 안 숫자는 "도(degree)" 기준
                              (예: sin(30) = 0.5. 라디안이 아님에 주의)
   asin, acos, atan, atan2   역삼각함수 — 결과도 도(degree) 단위로 나옴
   sinh, cosh, tanh          쌍곡선함수
   exp, log, ln              지수함수 / 자연로그(log와 ln은 같음)
   log10, log2                밑이 10, 2인 로그
   sqrt, cbrt                 제곱근, 세제곱근 (화면엔 실제 √, ∛ 기호로 보임)
   root(x, n)                  n제곱근 (예: root(8, 3) = 2, 화면엔 ⁿ√ 기호로 보임)
   abs                        절댓값
   round(x), round(x, n)      반올림 (n자리까지)
   ceil, floor                올림, 내림

지원하는 상수
   pi, e

위첨자 / 아래첨자 (제곱 표현법)
   수식 블록은 "_"(아래첨자) / "^"(위첨자) 다음에 오는 글자를 자동으로
   작게 표시합니다. 아래첨자는 여러 글자를 이어 써도 전부 작게 묶여서
   나옵니다(한 글자면 그대로, 두 글자 이상이면 자동으로 묶어서 표시).
      F_y          ->  F 아래에 y
      x^2          ->  x 위에 2  (위첨자는 한 글자만 자동으로 작아짐)
      x^2y         ->  x²y ("2"만 첨자, "y"는 보통 크기로 이어짐)
      sigma_allow  ->  σ 아래에 "allow" 전체가 작게 묶여서 표시(그리스 문자 변환도 같이 적용됨)

   변수 이름 자체는 sigma_allow처럼 얼마든지 길게 써도 계산엔 전혀 문제없고,
   화면 표시만 위 규칙을 따릅니다.

   (참고: 텍스트 블록은 반대로 "^{...}"/"_{...}"처럼 항상 중괄호가 있어야
   첨자로 인식됩니다 — 4번 항목 "텍스트 블록 사용법" 참고. 텍스트 블록은
   계산이 없는 자체 표시 전용 문법이라 LaTeX 충돌 문제가 없어서 중괄호로
   여러 글자를 묶는 걸 지원합니다.)

그리스 문자 변수명
   alpha, beta, gamma, delta, epsilon, zeta, eta, theta, iota, kappa,
   lambda, mu, nu, xi, pi, rho, sigma, tau, upsilon, phi, chi, psi, omega
   (그리고 대문자 Gamma, Delta, Theta, Lambda, Xi, Pi, Sigma, Upsilon, Phi,
   Psi, Omega)를 변수 이름에 그대로 쓰면 화면에는 실제 그리스 문자 기호로
   보입니다. 예: "sigma_allow = 140"이라고 입력하면 "σ_allow = 140"으로
   보입니다. 계산에 쓰이는 변수 이름은 여전히 "sigma_allow" 그대로라서,
   나중에 sigma_allow를 참조하는 다른 블록도 평소처럼 그대로 씁니다.
   "pixel"의 "pi"처럼 다른 단어의 일부로 들어있으면 건드리지 않습니다.

LaTeX 문법은 지원하지 않음
   "\frac{a}{b}", "\sqrt{x}", "\sum", "\int" 같은 백슬래시(\)나 중괄호({ })
   기반 LaTeX 문법은 아예 지원하지 않습니다. 입력해도 예쁘게 그려지지 않고
   원문 그대로 보이면서 "LaTeX 문법은 지원하지 않습니다"라는 에러가 뜹니다.
   (예전엔 화면엔 그럴듯하게 나오는데 계산만 안 되는 경우가 있어서 헷갈렸는데,
   아예 렌더링도 같이 포기하도록 정리했습니다.)

   대신 이 프로그램만의 함수 호출 문법을 쓰세요.
      \sqrt{x}      ->  sqrt(x)
      \frac{a}{b}   ->  a/b
      x^{10}        ->  x^10   (여러 자리 숫자도 중괄호 없이)

   (참고: sqrt(x), a/b, sigma 같은 이 프로그램 문법도 화면에는 √, 분수 막대,
   그리스 문자로 예쁘게 보입니다 — 위 "지원하는 연산자"/"지원하는 함수"/
   "그리스 문자 변수명" 참고. LaTeX 문법 자체(백슬래시, 중괄호)를 직접
   타이핑하는 것만 막혀 있는 것이고, 이 프로그램 문법으로 쓰면 계산도 되고
   화면도 예쁘게 나옵니다.)

계산 가능한 수준 (미적분/무한급수 등)
   이 프로그램은 기본적으로 "공학 계산서" 수준의 숫자 계산기입니다 — 사칙연산,
   위 함수들, 단위 계산이 공식적으로 지원·테스트된 범위입니다.

   다만 내부적으로 SymPy(강력한 심볼릭 수학 라이브러리)를 쓰기 때문에, 공식
   함수 목록에는 없지만 아래처럼 입력하면 실제로 계산되는 것들도 있습니다.
      limit(1/x, x, oo)              ->  0                (극한)
      solve(x^2-4, x)                ->  [-2, 2]           (방정식 풀이)
      nsolve(x^2-2, x, 1)            ->  1.41421...        (수치해석, 초기값 필요)
      integrate(x^2, (x, 0, 2))      ->  2.66667           (구간을 지정한 정적분)
      Sum(1/n^2, (n, 1, oo))         ->  1.64493...        (무한급수 합)
      Matrix([[1,2],[3,4]]), factorial(5) 등도 동작

   단, diff(x^2, x)나 부정적분처럼 결과에 변수가 그대로 남는 "기호식" 계산은
   안 됩니다. 계산 자체는 SymPy가 해내지만, 이 프로그램은 결과에 변수가
   남아있으면 무조건 "정의되지 않은 변수" 에러로 처리하도록 되어 있어서
   숫자 하나로 완전히 떨어지는 결과만 화면에 보여줄 수 있습니다. 그래서
   미분/적분도 구간이나 특정 값을 지정해서 숫자로 딱 떨어질 때만 보입니다.

   주의: 이 SymPy 직결 기능들은 공식적으로 테스트·보증된 게 아니라서 단위
   (kN, mm 등)와 섞으면 예상대로 안 될 수 있고, 나중에 내부 구조가 바뀌면
   사라질 수도 있습니다. 참고용으로만 쓰세요.

변수 이름
   영문/숫자/밑줄뿐 아니라 한글도 쓸 수 있습니다.
   예) sigma_허용 = 24

에러 처리
   정의되지 않은 변수를 쓰거나 수식이 잘못되면, 앱이 멈추지 않고
   블록 아래에 빨간색으로 에러 메시지가 표시됩니다.

한글이 섞인 수식 표시
   "sigma_허용" 처럼 한글이 섞인 입력은 일반 글꼴로,
   순수 영문/숫자 수식(a*sin(30) 등)은 더 예쁜 수식 글꼴로 표시됩니다.
   (계산 결과에는 차이가 없습니다 — 보이는 방식만 다릅니다.)


--------------------------------------------------------------------
4. 단위 계산
--------------------------------------------------------------------

숫자 뒤에 한 칸 띄우고 단위를 붙이면 그 값에 단위가 붙습니다.

   F = 200 kN
   b = 300 mm
   h = 500 mm
   A = b * h              ->  150000 mm^2   (단위도 자동으로 계산됨)
   sigma = F / A          ->  1.33333 MPa   (kN/mm^2 을 MPa로 자동 정리)
   sigma_허용 = 24 MPa
   OK = sigma < sigma_허용 ->  True          (단위가 있어도 비교 가능)

지원하는 단위
   길이   m, cm, mm, km, in, ft, yd
   면적   m^2, cm^2, mm^2, ft^2  (m*m 처럼 계산해도 자동으로 얻어짐)
   체적   m^3, cm^3, L, ft^3
   힘     N, kN, MN, kgf, tonf, lbf
   응력   Pa, kPa, MPa, GPa, psi, ksi
   모멘트  N*m, kN*m, kgf*m, lbf*ft  (힘 단위 * 길이 단위로 자동 계산됨)
   질량   kg, g, ton, lb
   시간   s, min, hr
   온도   degC, degF, K
   각도   deg, rad
   밀도   kg/m^3, kN/m^3

주의할 점
   - "ton"은 이 프로그램에서 한국 관례대로 미터톤(1000kg) 입니다.
     (Pint 라이브러리 기본값은 미국 톤(약 907kg)이라 별도로 바로잡아 두었습니다.)
   - "tonf"(톤힘) = 9.80665 kN 으로 계산됩니다.
   - kgf(킬로그램힘)와 kg(킬로그램 질량)은 서로 다른 단위이니 헷갈리지 마세요.
   - 숫자와 단위 사이는 띄어써도("200 kN") 붙여써도("200kN") 둘 다 인식됩니다.
   - 서로 다른 물리량(예: 길이와 힘)을 비교하거나 맞지 않는 단위끼리
     더하려고 하면, 앱이 멈추지 않고 에러 메시지가 표시됩니다.
   - 단위는 대소문자를 구분합니다(m=밀리 접두어, M=메가 접두어처럼 대소문자가
     아예 다른 뜻이라 엄격하게 구분해야 함). "MPa"는 꼭 대문자 M, 대문자
     P로 써야 인식됩니다 — "mpa", "Mpa"처럼 대소문자가 틀리면 단위로 인식되지
     않고, 그 줄 전체가 계산 에러로 처리됩니다(블록이 빨간 글씨로 바뀝니다 —
     아래 "화면 표시" 항목 참고). 계산이 에러인 블록의 변수는 정의되지 않은
     것으로 취급되어 변수 목록에도 나타나지 않습니다.

단위 자동완성
   숫자 바로 뒤에 글자를 치기 시작하면(예: "200 k") 후보 단위 목록이
   작은 팝업으로 뜹니다.
      위/아래 화살표  : 후보 이동
      Enter 또는 Tab  : 선택한 후보로 확정 (커서 뒤 일부만 바뀌고 나머지
                        수식은 그대로 유지됨)
      Esc             : 팝업만 닫기 (입력 중이던 내용은 그대로 남음)
      마우스 클릭      : 클릭한 후보로 바로 확정

   결과 표시 단위 편집창(Ctrl+더블클릭)에서도 똑같이 동작하며, 이땐
   입력창 전체가 단위 하나이므로 처음부터 후보가 뜹니다.
   변수 이름 등 숫자 뒤에 바로 오지 않는 글자에는 뜨지 않으므로, 일반
   변수명을 타이핑할 때는 방해가 되지 않습니다.


--------------------------------------------------------------------
5. 텍스트 블록 사용법
--------------------------------------------------------------------

Ctrl+더블클릭으로 만들며, 계산과 무관하게 제목이나 설명 등
자유 형식 글을 적는 용도입니다. 더블클릭하면 바로 타이핑할 수 있고,
바깥을 클릭하면 편집이 끝납니다.

위첨자 / 아래첨자
   편집할 때 다음 마크업을 쓰면 됩니다 (수식 블록의 ^, _ 표기와 같은 관례).

      ^{내용}   위첨자   예) x^{2}           ->  x²
      _{내용}   아래첨자  예) sigma_{허용}    ->  sigmaₐₗₗₒw (아래첨자로 작게)

   중괄호는 꼭 써야 합니다("x^2"는 위첨자로 인식되지 않고 글자 그대로
   보입니다). 중괄호 안에는 한글도 쓸 수 있습니다.
   예) H_{2}O, sigma_{허용} = 24 MPa

   편집 중에는(타이핑하는 동안) 마크업 원문("x^{2}")이 그대로 보이고,
   편집을 끝내고 바깥을 클릭하면 그때 위/아래첨자로 그려집니다.


--------------------------------------------------------------------
6. 이미지 블록 사용법
--------------------------------------------------------------------

이미지(단면도, 배치도 등)를 세 가지 방법으로 넣을 수 있습니다.

   (1) 메뉴: 파일 > 이미지 삽입... 을 누르고 파일을 고르면
       현재 화면 중앙에 삽입됩니다.
   (2) 드래그앤드롭: 탐색기에서 이미지 파일을 캔버스로 끌어다 놓으면
       놓은 자리에 삽입됩니다. 여러 개를 한 번에 끌어다 놓아도 됩니다.
   (3) 클립보드 붙여넣기(Ctrl+V): 스크린샷을 찍거나 다른 프로그램에서
       이미지를 복사한 뒤 캔버스에서 Ctrl+V를 누르면, 현재 화면 중앙에
       바로 삽입됩니다(파일로 먼저 저장할 필요 없음). 복사해둔 블록이
       있어도, 클립보드에 이미지가 있으면 이미지가 우선 붙여넣깁니다.

지원 형식: PNG, JPG, JPEG, BMP, SVG
   (SVG는 불러올 때 한 번 비트맵으로 변환됩니다. 원래 크기보다 아주 많이
    확대하면 다른 이미지와 마찬가지로 조금 흐려질 수 있습니다.)

블록 조작
   클릭            : 선택 (점선 테두리 + 우측 하단에 흰색 크기조절 손잡이 표시)
   몸통을 드래그     : 이동
   우측 하단 손잡이를 드래그 : 크기 조절
   선택 후 Delete    : 삭제

지원하지 않는 형식이거나 파일이 손상된 경우, 앱이 멈추지 않고
하단 상태바에 "이미지를 불러올 수 없습니다" 메시지가 표시됩니다.


--------------------------------------------------------------------
7. 파일 저장/불러오기
--------------------------------------------------------------------

메뉴 > 파일 에서 다음을 쓸 수 있습니다.

   새로 만들기 (Ctrl+N)         : 현재 문서를 비우고 새로 시작
   열기... (Ctrl+O)             : .engcalc 파일을 엽니다
   저장 (Ctrl+S)                : 현재 파일에 저장 (처음이면 "다른 이름으로 저장"과 동일)
   다른 이름으로 저장... (Ctrl+Shift+S) : 새 파일로 저장
   최근 파일                    : 최근에 열거나 저장한 파일 목록 (앱을 다시 켜도 남아있음,
                                  최대 10개). 목록 맨 아래 "최근 파일 지우기"로 비울 수
                                  있고, 비어 있으면 "(최근 파일 없음)"이 표시됩니다.

저장 형식은 사람이 읽을 수 있는 JSON(.engcalc)입니다. 캔버스 위 모든
블록(텍스트/수식/이미지)의 내용·위치·크기가 그대로 저장되고, 다시 열면
수식도 전부 재계산되어 원래와 같은 결과가 나옵니다.

창 제목 표시
   "파일명 - EngCalc"       : 저장된 상태 그대로
   "*파일명 - EngCalc"      : 저장 안 한 변경사항이 있음

저장 안 한 변경사항이 있는 상태로 "새로 만들기"/"열기"를 하거나 창을 닫으면,
저장할지 묻는 대화상자가 뜹니다.

새로 만들기: 문서 형식 고르기
   "새로 만들기"를 실행하면(저장 안 한 변경사항 확인 후) 문서 형식을 고르는
   대화상자가 뜹니다.

      자유 캔버스 (기존 방식) : 지금까지와 같은, 페이지 구분 없는 넓은 캔버스
      문서 (용지 기반)        : A4 용지를 세로로 이어붙인 모양의 캔버스.
                               회색 배경 위에 흰 용지가 놓이고, 페이지마다
                               아래쪽에 "N / 전체" 쪽 번호가 표시됩니다.
                               내용이 마지막 용지를 넘어가면 아래에 새 용지가
                               자동으로 늘어납니다(항상 빈 용지 한 장이 여유로
                               남아 있음).

   고른 형식은 그 문서에 고정되어 파일에 함께 저장되고, 다시 열어도 그대로
   유지됩니다. 문서를 만든 뒤에 형식만 바꾸는 기능은 없습니다 — 형식을
   바꾸고 싶으면 "새로 만들기"로 원하는 형식의 새 문서를 만드세요.
   (참고: PDF로 내보내기는 문서 형식과 무관하게 항상 A4 용지·여백 기준으로
   나오므로, 화면의 용지 구분과 PDF의 페이지 나뉨이 정확히 일치하진 않습니다.)

자동 저장 / 비정상 종료 복구
   저장 안 한 변경사항이 있으면 1분마다 자동으로 임시 위치(사용자 폴더의
   ".engcalc/autosave.engcalc", 실제로 저장하는 파일과는 별개)에 백업해둡니다.
   프로그램을 정상적으로 저장/새 문서/열기/종료하면 이 백업은 바로 지워집니다.

   만약 강제 종료나 정전, 크래시로 비정상 종료됐다면 이 백업이 그대로 남아있게
   되고, 다음에 프로그램을 실행하면 "자동 저장된 내용을 복구할까요?"라고
   물어봅니다. "예"를 누르면 마지막 자동 저장 시점의 내용으로 캔버스가
   복원되고(원래 저장하던 파일 경로도 함께 기억해둠), 창 제목에 "*"가 표시되어
   아직 실제 파일로 저장하지 않았다는 걸 알려줍니다 — 내용을 확인한 뒤
   Ctrl+S로 저장하세요. "아니오"를 누르면 백업을 버리고 빈 문서로 시작합니다.


--------------------------------------------------------------------
8. 문서 속성 / PDF로 내보내기 / PNG로 내보내기 / 인쇄
--------------------------------------------------------------------

문서 속성 (메뉴 > 파일 > 문서 속성...)
   문서의 제목/작성자를 정하고, PDF/인쇄에 머리글·바닥글을 표시할지 고르는
   대화상자입니다.

      제목   : 비워두면 파일명을 대신 씁니다(창 제목 표시줄은 항상
               파일명 기준이고, 이 제목은 PDF/인쇄 머리글에만 쓰입니다).
      작성자 : 설정하면 PDF/인쇄 머리글에 "작성: OOO"로 표시됩니다.
      "PDF로 내보내기/인쇄 시 머리글·바닥글 표시" : 기본은 꺼져 있습니다.
               켜면 제목/작성자/날짜(머리글)와 쪽 번호(바닥글)가 함께 찍힙니다.

   여기서 정한 값은 파일에 저장되어 다시 열어도 유지됩니다. "새로 만들기"를
   하면 새 문서는 다시 빈 값(꺼짐)으로 시작합니다.

메뉴 > 파일 > PDF로 내보내기... 를 누르면 현재 캔버스를 A4 PDF로 저장합니다.

   - 화면에 보이는 그대로(수식, 텍스트 서식, 이미지) PDF에 반영됩니다.
   - 배경 격자는 인쇄용으로 지저분해 보여서 PDF에는 찍히지 않습니다.
   - 화면에서 보이는 크기 그대로 찍힙니다(억지로 페이지 폭에 맞춰 확대하지
     않음) — 내용이 본문 폭보다 넓을 때만 페이지에 맞게 줄어듭니다.
   - 내용이 A4 한 장보다 길면 자동으로 여러 페이지로 나뉩니다.
   - 머리글/바닥글은 "문서 속성"에서 켰을 때만 찍힙니다(위 참고).
   - 캔버스에 블록이 하나도 없으면 내보낼 내용이 없다는 안내만 뜨고
     PDF 파일은 만들어지지 않습니다.

메뉴 > 파일 > PNG로 내보내기... 를 누르면 현재 캔버스 내용을 이미지 파일
하나로 저장합니다. 워드/한글 등 다른 문서에 계산 결과를 그림으로 붙여넣고
싶을 때 PDF보다 바로 쓰기 편합니다.

   - PDF와 달리 페이지 개념이 없어서, 내용 전체가 여백만 살짝 두고 한 장의
     이미지에 그대로 담깁니다(억지로 줄이거나 늘리지 않음).
   - 화면보다 또렷하게 보이도록 기본으로 2배 확대해서 저장합니다.
   - 배경은 항상 흰색이고(격자 없음), 문서 형식이 "A4 용지"여도 PNG에는
     회색 배경/쪽 경계가 찍히지 않습니다(PDF와 동일).
   - 캔버스에 블록이 하나도 없으면 내보낼 내용이 없다는 안내만 뜨고
     이미지 파일은 만들어지지 않습니다.

인쇄 (Ctrl+P)
   메뉴 > 파일 > 인쇄... 또는 Ctrl+P로 인쇄 대화상자를 엽니다. 프린터/용지/
   매수 등은 운영체제의 표준 인쇄 대화상자에서 고릅니다 — 대화상자를 열기
   전에 기본값을 A4·여백 20mm로 맞춰두지만, 대화상자에서 다른 용지나
   방향을 고르면 그 선택을 그대로 따릅니다. 페이지 나누기/배율/머리글·
   바닥글은 PDF로 내보내기와 완전히 같은 방식으로 계산됩니다. 캔버스에
   블록이 하나도 없으면 인쇄 대화상자조차 뜨지 않고 안내만 표시됩니다.

9. 속성 패널 / 변수 목록
--------------------------------------------------------------------

창 오른쪽에 두 패널이 탭으로 겹쳐 있습니다(보기 메뉴에서 각각 켜고 끌 수
있음). 처음엔 "속성" 탭이 보이고, 아래쪽 탭을 눌러 "변수 목록"으로 바꿀 수
있습니다.

속성 패널
   블록을 클릭하면 그 블록의 속성이 뜹니다.
      - 모든 블록: 위치(X, Y) — 값을 바꾸면 블록이 그 자리로 이동
      - 이미지 블록: 너비/높이 — 손잡이로 드래그하지 않고 숫자로 직접 지정 가능
      - 텍스트 블록: 굵게, 글자 크기
      - 수식 블록: 표시 단위 — 예를 들어 계산 결과가 자동으로 MPa로
        나왔더라도 "kPa"라고 입력하면 그 단위로 바꿔서 보여줍니다.
        (실제 계산값은 그대로이고, 보여주는 방식만 바뀝니다. 빈 칸으로
        두면 다시 자동으로 정리된 단위로 돌아갑니다.)
   블록을 선택 해제하면 "선택된 블록 없음" 상태로 비워집니다.

변수 목록
   현재 문서에서 대입된("이름 = 값") 모든 변수와 값을 목록으로 보여줍니다.
   목록의 변수를 더블클릭하면, 그 변수를 정의한 수식 블록으로 캔버스가
   스크롤 이동하고 그 블록이 선택됩니다. 변수 값이 바뀌면 목록도 자동으로
   갱신됩니다.

10. 문제가 생겼을 때
--------------------------------------------------------------------

   "ModuleNotFoundError" 가 뜨는 경우
      -> pip install -r requirements.txt 를 다시 실행해보세요.
         (venv를 쓰고 있다면 venv\Scripts\activate 로 먼저 활성화)

   더블클릭해도 아무 반응이 없는 경우
      -> git pull로 최신 코드를 받았는지 확인해보세요.
