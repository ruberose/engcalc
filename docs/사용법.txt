1. 실행 방법
--------------------------------------------------------------------

1) 처음 한 번만: 필요한 패키지 설치
   pip install -r requirements.txt

2) 실행

   -> 격자 배경의 빈 창이 뜨면 정상입니다.

2. 캔버스 기본 조작법
--------------------------------------------------------------------

블록 만들기
   더블클릭            : 그 자리에 "수식 블록"을 만듭니다.
   Ctrl + 더블클릭     : 그 자리에 "텍스트 블록"을 만듭니다.
   (이 프로그램의 핵심 기능이 계산이므로, 아무 표시 없는 더블클릭의
    기본 동작은 수식 블록입니다. 제목/설명 등 글만 쓰고 싶을 때만
    Ctrl을 눌러주세요.)

블록 선택/이동
   블록 클릭           : 선택 (점선 테두리로 표시됨)
   블록을 드래그        : 이동
   빈 캔버스를 드래그    : 여러 블록을 한 번에 선택(러버밴드 선택)

블록 편집
   블록을 더블클릭      : 편집 모드로 들어감 (수식/텍스트 모두 동일)
   편집 중 바깥을 클릭   : 편집 종료 및 내용 반영
   편집 중 Enter        : (수식 블록만) 편집 종료 및 내용 반영

블록 삭제
   블록을 선택한 뒤 Delete 또는 Backspace

실행취소 / 다시실행 / 복사 / 붙여넣기
   Ctrl+Z              : 실행취소 (블록 생성/삭제/이동/크기조절/내용변경/붙여넣기 등
                          문서에 생긴 변화를 한 단계씩 되돌림)
   Ctrl+Y              : 다시실행 (Ctrl+Z로 되돌린 것을 다시 앞으로)
   Ctrl+C              : 선택된 블록(들) 복사
   Ctrl+V              : 복사한 블록(들)을 원본에서 살짝 어긋난 위치에 붙여넣기

   메뉴 > 편집 에서도 같은 기능을 쓸 수 있습니다. 블록을 편집(타이핑) 중일 때는
   이 단축키들이 편집기 자체의 텍스트 실행취소/복사/붙여넣기로 쓰이고, 문서
   단위 동작은 편집 중이 아닐 때만 적용됩니다. 붙여넣은 블록은 새 블록으로
   취급되어(원본과 다른 고유 id) 원본과 독립적으로 움직이거나 지울 수 있습니다.
   실행취소 기록은 최근 50단계까지 보관됩니다.

화면 조작
   마우스 휠            : 커서 위치를 중심으로 확대/축소
   Space를 누른 채 드래그 : 캔버스 전체를 스크롤(패닝)

3. 수식 블록 사용법
--------------------------------------------------------------------

입력 형식은 두 가지입니다.

   (1) 변수 대입      예) a = 100
   (2) 그냥 계산식     예) a * 2 + 1

변수 대입을 하면 그 변수는 캔버스의 "아래쪽(또는 같은 높이면 오른쪽)"에
있는 다른 수식 블록에서 그대로 쓸 수 있습니다. 즉 블록은 화면에 놓인
위→아래, 왼→오른 순서대로 계산됩니다.

   [블록 1]  a = 100
   [블록 2]  a * sin(30)     ->  결과: 50   (a=100 을 이어받아 계산)

어떤 블록의 값을 바꾸면, 그 값을 참조하는 다른 모든 블록도
자동으로 다시 계산됩니다. 값을 계속 바꿔가며 검산할 때 편리합니다.

화면 표시 (한 줄 / 두 줄)
   기본적으로 "입력 = 결과"를 파워포인트 글상자처럼 한 줄로 표시합니다.
   (예: "A + B = 15 m". "a = 100"처럼 입력 자체가 이미 값이면 결과를
   중복해서 보여주지 않습니다.)

   블록을 클릭해서 선택하면 우측 가장자리에 작은 손잡이가 나타납니다.
   이 손잡이를 드래그해서 폭을 좁히면, 한 줄에 다 안 들어갈 때 입력 줄과
   "= 결과" 줄로 나뉩니다(줄바꿈). 폭을 다시 넓히거나 아예 손잡이를
   건드리지 않으면 항상 내용에 맞춰 한 줄로 넓어집니다. 줄바꿈은 보여주는
   방식만 바꿀 뿐, 계산 결과 자체는 바뀌지 않습니다.

결과 단위 바로 바꾸기 (Ctrl+더블클릭)
   결과가 단위 있는 값(예: "5m + 6m = 11m")일 때, 블록을 Ctrl+더블클릭하면
   단위만 편집할 수 있는 작은 입력창이 뜹니다. 지금 단위("m")가 미리
   채워져 있고, 다른 단위(예: "mm")로 바꿔서 Enter를 누르면:

      5m + 6m = 11m   ->  (Ctrl+더블클릭, "mm"으로 변경) ->  5m + 6m = 11000mm

   값이 그 단위에 맞춰 자동으로 환산되어 보입니다. 실제 계산에 쓰이는
   값은 그대로이고(다른 블록의 계산에 영향 없음), 보여주는 단위만 바뀝니다.
   같은 걸 속성 패널의 "표시 단위" 입력으로도 할 수 있습니다.
   말이 안 되는 단위를 입력하면(예: "asdf") 조용히 무시되고 원래 값이
   그대로 보입니다. 단위 없는 순수 숫자나 에러 상태인 블록은 바꿀 단위가
   없어서 Ctrl+더블클릭해도 아무 일도 일어나지 않습니다.

지원하는 연산자
   +  -  *  /       사칙연산 (곱하기는 입력할 땐 "*"지만, 화면에는 실제 수식처럼
                     가운뎃점(·)으로 표시됩니다 — 예: "A*B"라고 입력하면 "A·B"로
                     보임. 계산이나 저장되는 내용에는 차이가 없습니다.)
   ^                거듭제곱 (예: 2^10 = 1024)
   %                나머지
   <  >  <=  >=  == 비교 (결과가 True / False로 표시됨)

지원하는 함수
   sin, cos, tan             삼각함수 — 괄호 안 숫자는 "도(degree)" 기준
                              (예: sin(30) = 0.5. 라디안이 아님에 주의)
   asin, acos, atan, atan2   역삼각함수 — 결과도 도(degree) 단위로 나옴
   sinh, cosh, tanh          쌍곡선함수
   exp, log, ln              지수함수 / 자연로그(log와 ln은 같음)
   log10, log2                밑이 10, 2인 로그
   sqrt, cbrt                 제곱근, 세제곱근
   root(x, n)                  n제곱근 (예: root(8, 3) = 2)
   abs                        절댓값
   round(x), round(x, n)      반올림 (n자리까지)
   ceil, floor                올림, 내림

지원하는 상수
   pi, e

계산 가능한 수준 (미적분/무한급수 등)
   이 프로그램은 기본적으로 "공학 계산서" 수준의 숫자 계산기입니다 — 사칙연산,
   위 함수들, 단위 계산이 공식적으로 지원·테스트된 범위입니다.

   다만 내부적으로 SymPy(강력한 심볼릭 수학 라이브러리)를 쓰기 때문에, 공식
   함수 목록에는 없지만 아래처럼 입력하면 실제로 계산되는 것들도 있습니다.
      limit(1/x, x, oo)              ->  0                (극한)
      solve(x^2-4, x)                ->  [-2, 2]           (방정식 풀이)
      nsolve(x^2-2, x, 1)            ->  1.41421...        (수치해석, 초기값 필요)
      integrate(x^2, (x, 0, 2))      ->  2.66667           (구간을 지정한 정적분)
      Sum(1/n^2, (n, 1, oo))         ->  1.64493...        (무한급수 합)
      Matrix([[1,2],[3,4]]), factorial(5) 등도 동작

   단, diff(x^2, x)나 부정적분처럼 결과에 변수가 그대로 남는 "기호식" 계산은
   안 됩니다. 계산 자체는 SymPy가 해내지만, 이 프로그램은 결과에 변수가
   남아있으면 무조건 "정의되지 않은 변수" 에러로 처리하도록 되어 있어서
   숫자 하나로 완전히 떨어지는 결과만 화면에 보여줄 수 있습니다. 그래서
   미분/적분도 구간이나 특정 값을 지정해서 숫자로 딱 떨어질 때만 보입니다.

   주의: 이 SymPy 직결 기능들은 공식적으로 테스트·보증된 게 아니라서 단위
   (kN, mm 등)와 섞으면 예상대로 안 될 수 있고, 나중에 내부 구조가 바뀌면
   사라질 수도 있습니다. 참고용으로만 쓰세요.

변수 이름
   영문/숫자/밑줄뿐 아니라 한글도 쓸 수 있습니다.
   예) sigma_허용 = 24

에러 처리
   정의되지 않은 변수를 쓰거나 수식이 잘못되면, 앱이 멈추지 않고
   블록 아래에 빨간색으로 에러 메시지가 표시됩니다.

한글이 섞인 수식 표시
   "sigma_허용" 처럼 한글이 섞인 입력은 일반 글꼴로,
   순수 영문/숫자 수식(a*sin(30) 등)은 더 예쁜 수식 글꼴로 표시됩니다.
   (계산 결과에는 차이가 없습니다 — 보이는 방식만 다릅니다.)

4. 단위 계산
--------------------------------------------------------------------

숫자 뒤에 한 칸 띄우고 단위를 붙이면 그 값에 단위가 붙습니다.

   F = 200 kN
   b = 300 mm
   h = 500 mm
   A = b * h              ->  150000 mm^2   (단위도 자동으로 계산됨)
   sigma = F / A          ->  1.33333 MPa   (kN/mm^2 을 MPa로 자동 정리)
   sigma_허용 = 24 MPa
   OK = sigma < sigma_허용 ->  True          (단위가 있어도 비교 가능)

지원하는 단위
   길이   m, cm, mm, km, in, ft, yd
   면적   m^2, cm^2, mm^2, ft^2  (m*m 처럼 계산해도 자동으로 얻어짐)
   체적   m^3, cm^3, L, ft^3
   힘     N, kN, MN, kgf, tonf, lbf
   응력   Pa, kPa, MPa, GPa, psi, ksi
   모멘트  N*m, kN*m, kgf*m, lbf*ft  (힘 단위 * 길이 단위로 자동 계산됨)
   질량   kg, g, ton, lb
   시간   s, min, hr
   온도   degC, degF, K
   각도   deg, rad
   밀도   kg/m^3, kN/m^3

주의할 점
   - "ton"은 이 프로그램에서 한국 관례대로 미터톤(1000kg) 입니다.
     (Pint 라이브러리 기본값은 미국 톤(약 907kg)이라 별도로 바로잡아 두었습니다.)
   - "tonf"(톤힘) = 9.80665 kN 으로 계산됩니다.
   - kgf(킬로그램힘)와 kg(킬로그램 질량)은 서로 다른 단위이니 헷갈리지 마세요.
   - 숫자와 단위 사이는 띄어써도("200 kN") 붙여써도("200kN") 둘 다 인식됩니다.
   - 서로 다른 물리량(예: 길이와 힘)을 비교하거나 맞지 않는 단위끼리
     더하려고 하면, 앱이 멈추지 않고 에러 메시지가 표시됩니다.
   - 아직 단위 입력 자동완성 기능은 없습니다.

5. 텍스트 블록 사용법
--------------------------------------------------------------------

Ctrl+더블클릭으로 만들며, 계산과 무관하게 제목이나 설명 등
자유 형식 글을 적는 용도입니다. 더블클릭하면 바로 타이핑할 수 있고,
바깥을 클릭하면 편집이 끝납니다.

위첨자 / 아래첨자
   편집할 때 다음 마크업을 쓰면 됩니다 (수식 블록의 ^, _ 표기와 같은 관례).

      ^{내용}   위첨자   예) x^{2}           ->  x²
      _{내용}   아래첨자  예) sigma_{허용}    ->  sigmaₐₗₗₒw (아래첨자로 작게)

   중괄호는 꼭 써야 합니다("x^2"는 위첨자로 인식되지 않고 글자 그대로
   보입니다). 중괄호 안에는 한글도 쓸 수 있습니다.
   예) H_{2}O, sigma_{허용} = 24 MPa

   편집 중에는(타이핑하는 동안) 마크업 원문("x^{2}")이 그대로 보이고,
   편집을 끝내고 바깥을 클릭하면 그때 위/아래첨자로 그려집니다.

6. 이미지 블록 사용법
--------------------------------------------------------------------

이미지(단면도, 배치도 등)를 두 가지 방법으로 넣을 수 있습니다.

   (1) 메뉴: 파일 > 이미지 삽입... 을 누르고 파일을 고르면
       현재 화면 중앙에 삽입됩니다.
   (2) 드래그앤드롭: 탐색기에서 이미지 파일을 캔버스로 끌어다 놓으면
       놓은 자리에 삽입됩니다. 여러 개를 한 번에 끌어다 놓아도 됩니다.

지원 형식: PNG, JPG, JPEG, BMP, SVG
   (SVG는 불러올 때 한 번 비트맵으로 변환됩니다. 원래 크기보다 아주 많이
    확대하면 다른 이미지와 마찬가지로 조금 흐려질 수 있습니다.)

블록 조작
   클릭            : 선택 (점선 테두리 + 우측 하단에 흰색 크기조절 손잡이 표시)
   몸통을 드래그     : 이동
   우측 하단 손잡이를 드래그 : 크기 조절
   선택 후 Delete    : 삭제

지원하지 않는 형식이거나 파일이 손상된 경우, 앱이 멈추지 않고
하단 상태바에 "이미지를 불러올 수 없습니다" 메시지가 표시됩니다.

7. 파일 저장/불러오기
--------------------------------------------------------------------

메뉴 > 파일 에서 다음을 쓸 수 있습니다.

   새로 만들기 (Ctrl+N)         : 현재 문서를 비우고 새로 시작
   열기... (Ctrl+O)             : .engcalc 파일을 엽니다
   저장 (Ctrl+S)                : 현재 파일에 저장 (처음이면 "다른 이름으로 저장"과 동일)
   다른 이름으로 저장... (Ctrl+Shift+S) : 새 파일로 저장
   최근 파일                    : 최근에 열거나 저장한 파일 목록 (앱을 다시 켜도 남아있음)

저장 형식은 사람이 읽을 수 있는 JSON(.engcalc)입니다. 캔버스 위 모든
블록(텍스트/수식/이미지)의 내용·위치·크기가 그대로 저장되고, 다시 열면
수식도 전부 재계산되어 원래와 같은 결과가 나옵니다.

창 제목 표시
   "파일명 - EngCalc"       : 저장된 상태 그대로
   "*파일명 - EngCalc"      : 저장 안 한 변경사항이 있음

저장 안 한 변경사항이 있는 상태로 "새로 만들기"/"열기"를 하거나 창을 닫으면,
저장할지 묻는 대화상자가 뜹니다.


--------------------------------------------------------------------
8. PDF로 내보내기
--------------------------------------------------------------------

메뉴 > 파일 > PDF로 내보내기... 를 누르면 현재 캔버스를 A4 PDF로 저장합니다.

   - 화면에 보이는 그대로(수식, 텍스트 서식, 이미지) PDF에 반영됩니다.
   - 배경 격자는 인쇄용으로 지저분해 보여서 PDF에는 찍히지 않습니다.
   - 내용이 A4 한 장보다 길면 자동으로 여러 페이지로 나뉩니다.
   - 각 페이지 머리글에 문서 제목과 날짜, 바닥글에 "N / 전체 페이지"가
     자동으로 들어갑니다.
   - 캔버스에 블록이 하나도 없으면 내보낼 내용이 없다는 안내만 뜨고
     PDF 파일은 만들어지지 않습니다.


--------------------------------------------------------------------
9. 속성 패널 / 변수 목록
--------------------------------------------------------------------

창 오른쪽에 두 패널이 탭으로 겹쳐 있습니다(보기 메뉴에서 각각 켜고 끌 수
있음). 처음엔 "속성" 탭이 보이고, 아래쪽 탭을 눌러 "변수 목록"으로 바꿀 수
있습니다.

속성 패널
   블록을 클릭하면 그 블록의 속성이 뜹니다.
      - 모든 블록: 위치(X, Y) — 값을 바꾸면 블록이 그 자리로 이동
      - 이미지 블록: 너비/높이 — 손잡이로 드래그하지 않고 숫자로 직접 지정 가능
      - 텍스트 블록: 굵게, 글자 크기
      - 수식 블록: 표시 단위 — 예를 들어 계산 결과가 자동으로 MPa로
        나왔더라도 "kPa"라고 입력하면 그 단위로 바꿔서 보여줍니다.
        (실제 계산값은 그대로이고, 보여주는 방식만 바뀝니다. 빈 칸으로
        두면 다시 자동으로 정리된 단위로 돌아갑니다.)
   블록을 선택 해제하면 "선택된 블록 없음" 상태로 비워집니다.

변수 목록
   현재 문서에서 대입된("이름 = 값") 모든 변수와 값을 목록으로 보여줍니다.
   목록의 변수를 더블클릭하면, 그 변수를 정의한 수식 블록으로 캔버스가
   스크롤 이동하고 그 블록이 선택됩니다. 변수 값이 바뀌면 목록도 자동으로
   갱신됩니다.

10. 문제가 생겼을 때
--------------------------------------------------------------------

   "ModuleNotFoundError" 가 뜨는 경우
      -> pip install -r requirements.txt 를 다시 실행해보세요.
         (venv를 쓰고 있다면 venv\Scripts\activate 로 먼저 활성화)

   더블클릭해도 아무 반응이 없는 경우
      -> git pull로 최신 코드를 받았는지 확인해보세요.
